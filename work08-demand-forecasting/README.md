# Work 08: Demand Forecasting & Inventory Optimization

Виробничий проєкт прогнозування попиту на часових рядах для ролі **Senior ML Engineer**.

## Ключові інженерні особливості

1. **Суворий бектестинг без витоку даних (Zero Lookahead):**
   * 4-фолдовий послідовний expanding-window бектестинг на 20 часових рядах (21,920 днів каліброваної симуляції з агро-динамікою).
   * Горизонт $H=14$ днів: усі лаги та ковзні агрегати зміщені мінімум на 14 днів ($t - H$).
   * Ковзні статистики розраховуються суворо окремо для кожного `hub_id × sku_id` (`groupby transform`) без перетікання на межах рядів.
2. **Чесні бейзлайни (Baselines):**
   * Seasonal Naive ($y_{t-7}$) та Historical Day-of-Week 4-Week Moving Average.
   * LightGBM перевершує Seasonal Naive на **38.76% за метрикою WAPE** (7.22% проти 11.79%).
3. **Оптимізація асиметричного ризику (Newsvendor Inventory Policy):**
   * Штраф за дефіцит $C_{under} = 5.0$, вартість зберігання $C_{over} = 1.0$.
   * Квантильний бустинг на критичному квантилі $\tau^* = 83.33\%$ знижує змодельовані фінансові втрати складу на **49.58%**.
   * Емпіричне покриття довірчого інтервалу $[P_{10}, P_{90}]$: **80.7%** (таргет 80.0%).
4. **Поглиблений сегментний аналіз:**
   * Розклад похибок по 4 категоріях SKU, 5 регіональних хабах, днях тижня та промокампаніях (+55.9% переваги під час акцій).
5. **Продакшн сервінг (FastAPI):**
   * Ендпоінти `/v1/health` та `/v1/forecast`.
   * Контракт: фіксований операційний горизонт $H=14$ днів із валідацією контракту (HTTP 422 при спробі порушити горизонт).
   * Час інференсу: **~61 мс** на 14-денний горизонт з довірчими інтервалами.
