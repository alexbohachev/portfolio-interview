# Work 08: Demand Forecasting & Inventory Optimization

Виробничий проєкт прогнозування попиту на часових рядах для ролі **Senior ML Engineer**.

## Ключові інженерні особливості

1. **Суворий бектестинг без витоку даних та нульовий Train-Serving Skew (Zero Lookahead & Ex-Ante Alignment):**
   * 4-фолдовий послідовний expanding-window бектестинг на 20 часових рядах (21,920 спостережень каліброваної симуляції з агро-динамікою) через 4 реальні агро-сезони (весняна посівна, літній догляд, осінній збір/посів, зимове міжсезоння).
   * Горизонт $H=14$ днів: усі лаги та ковзні агрегати зміщені мінімум на 14 днів ($t - H$).
   * Ковзні статистики розраховуються суворо окремо для кожного `hub_id × sku_id` (`groupby transform`) без перетікання на межах рядів.
   * **Єдиний Ex-Ante пайплайн (`build_ex_ante_features`):** тестові фолди використовують рівно ту інформацію, яка доступна API на момент прогнозу $T_0$ (перенесення останньої ціни, кліматологічна очікувана температура без шуму, плановий графік промо).
2. **Чесні бейзлайни (Baselines):**
   * Seasonal Naive ($y_{t-7}$) та Historical Day-of-Week 4-Week Moving Average.
   * На симуляції агро-попиту LightGBM перевершує Seasonal Naive на **40.68% за метрикою WAPE** (7.83% проти 13.20% у середньому за всіма сезонами).
3. **Оптимізація асиметричного ризику (Newsvendor Inventory Policy) та калібрування інтервалів (CQR):**
   * Штраф за дефіцит $C_{under} = 5.0$, вартість зберігання $C_{over} = 1.0$.
   * Квантильний бустинг на критичному квантилі $\tau^* = 83.33\%$ знижує змодельовані фінансові втрати складу на **43.06%** (з 7,308.0 до 4,160.9 у.о.).
   * Спліт-конформне калібрування (CQR) забезпечило **спостережуване покриття $\ge 80.0\%$ на всіх чотирьох синтетичних тестових зрізах** (середнє **84.11%** проти 75.90% некаліброваного).
4. **Валідація на реальних даних (Capital Bikeshare) та інженерне рішення Senior ML:**
   * На реальних сенсорних даних (1 456 записів, 2011–2012 рр.) із сильним нестаціонарним трендом розширення станцій простий бейзлайн Seasonal Naive переміг LightGBM (WAPE 35.42% проти 37.74%; витрати складу 33,576 проти 51,630 у.о.).
   * **Рішення для продакшну Bikeshare:** розгортати Seasonal Baseline (бритва Оккама, нульові витрати на інференс та моніторинг дрейфу). Калібрування CQR підняло покриття з 26.79% до 75.89% (нижче 80% через порушення exchangeability трендом).
5. **Поглиблений сегментний аналіз:**
   * Розклад похибок по 4 агро-сезонах (ліфт від +13.7% до +53.1%), 4 категоріях SKU, 5 регіональних хабах, днях тижня та промокампаніях.
6. **Продакшн сервінг (FastAPI):**
   * Ендпоінти `/v1/health` та `/v1/forecast`.
   * Контракт: фіксований операційний горизонт $H=14$ днів із валідацією контракту (HTTP 422 при спробі порушити горизонт) та опціональною підтримкою `planned_promos`.
   * Час інференсу: **~55–65 мс** на 14-денний горизонт з каліброваними квантильними інтервалами.
